### MarkDown 語法小抄
| 功能 | 語法 | 範例與說明 |
|------|------|------------|
| 標題 | `#` 到 `######` | `# H1`、`## H2`... |
| 粗體 | `**文字**` | `**重要說明**` |
| 斜體 | `*文字*` | `*次要說明*` |
| 清單 | `-` 或 `*` | `- 項目一` |
| 編號清單 | `1. 2. 3.` | `1. 步驟一` |
| 區塊程式碼 | ```` ```python ... ``` ```` | 可顯示整段程式 |
| 行內程式碼 | `` `print("hi")` `` | 顯示單行 `print()` |
| 圖片 | `![文字說明](圖片路徑或網址)` | 加截圖 |
| 連結 | `[說明文字](網址)` | `[前往GitHub](https://github.com)` |
| 水平線 | `---` | 分隔段落用 |
